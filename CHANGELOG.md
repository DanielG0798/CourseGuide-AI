# Changelog

All notable changes to CourseGuide AI are documented in this file.

## [0.1.0] — 2026-09-09

### Added
- Repository skeleton with Python package structure.
- `src/m2/agent.py`: Milestone 2 prototype using OpenAI Agents SDK and MCP.
- `mcp_servers/course_policy_mcp.py`: MCP server with course policy tools.
- `src/shared/`: Config loader, model client, tracing helper.
- Sample course policies in `config/`.
- M2 test cases and pytest harness.
- Milestone report templates in `docs/`.
- README with setup instructions and plain-language folder guide.
